# Contact Manager

A command-line contact management system built with pure Python.

## Features
- Add, view, search, update and delete contacts.
- Persistent storage using JSON ('contact.json').
- Object-Oriented design (Separation of Data and Logic).
- Input validation for name, phone numbers and emails.
  
## How to Run
1. Ensure you have Python installed.
2. Run 'python contact.py' in your terminal.
